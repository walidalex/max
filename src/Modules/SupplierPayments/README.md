# Supplier Payments

تسدد هذه الوحدة فواتير الموردين المعتمدة فقط. ترحيل الدفعة يقفل فاتورة المورد، يعيد حساب إجمالي المدفوع والمتبقي باستخدام `DECIMAL` داخل المعاملة، ثم يجمد snapshots الهوية والقيم. لا تنشئ الوحدة تكاليف مشروع؛ التكلفة والدائن ينشآن عند اعتماد فاتورة المورد. الدفعة المرحلة نهائية، والمسودة فقط قابلة للتعديل أو الإلغاء. التصحيحات والعكس المحاسبي وGL خارج النطاق الحالي.
