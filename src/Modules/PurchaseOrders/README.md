# Purchase Orders

Phase 1 records a vendor purchase commitment against a project and cost codes.

- Workflow: `draft -> approved` or `draft -> cancelled`.
- Only drafts are editable or cancellable; approved and cancelled records are immutable.
- Approval freezes vendor, project, work-section, cost-code snapshots and the database-calculated total.
- Approval does not create a Project Actual Cost, supplier invoice, payable, payment, inventory movement, tax entry, or GL entry.
- Line totals are generated by MariaDB from DECIMAL quantity and unit price; PHP never performs monetary floating-point arithmetic.
- Future supplier-invoice linking must be added as a separate phase without changing this commitment-only invariant.
